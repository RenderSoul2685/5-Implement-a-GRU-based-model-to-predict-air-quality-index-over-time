🔬 About the AQI-GRU Next-Day Forecasting Project

Technical documentation of authentic monitoring data, deep learning model architecture, empirical benchmark evaluation, and scope limitations.

1. Data & Provenance

The project relies exclusively on real CPCB readings across 6 Delhi monitoring stations spanning 2023–2025, sourced from the OpenCity Delhi Air Quality repository republished from the Central Pollution Control Board (CPCB) / DPCC CAAQMS network:

  • Anand Vihar (Eastern transit corridor / interstate bus terminal)
  • Bawana (North-West industrial zone)
  • ITO (Central high-traffic arterial intersection)
  • Mandir Marg (Central institutional background site)
  • Punjabi Bagh (West Delhi commercial and residential regime)
  • RK Puram (South Delhi urban residential sector)

Daily Aggregation & AQI Computation: Daily means are computed strictly from days with at least 18 valid hours (75% CPCB completeness criterion). Days with fewer than 18 valid hours are treated as unobserved (NaN). 2023 AQI is the published value from official CPCB bulletins; 2024–25 AQI was computed from pollutant readings ($\text{PM}_{2.5}, \text{PM}_{10}, \text{NO}_2, \text{SO}_2, \text{CO}, \text{O}_3$) aggregated from 15-minute sensor telemetry across official CPCB linear sub-index breakpoints.

Interpolation Policy: Gaps of up to 2 days only are linearly interpolated. Longer gaps remain missing, and windows containing them are excluded. Ground truth scoring is conducted strictly on observed target days.

2. Model Architecture

The predictive core uses a recurrent neural network designed for sequence-to-scalar forecasting:

  • Model Architecture: 2-layer GRU (hidden dimension: 64 units per layer, dropout: 0.20) with a linear projection head.
  • Input Context: 14-day historical lookback comprising past daily mean AQI, daily weather (temperature, humidity, wind speed, pressure), and cyclical day-of-week and month sine/cosine encodings (9 features total).
  • Target Parameterization: Next-day target with a residual formulation: the model predicts tomorrow's step-wise delta ($\Delta \text{AQI}_{t+1} = \text{AQI}_{t+1} - \text{AQI}_t$). This delta is unscaled, added back to today's anchor AQI ($\text{AQI}_t$), and clipped to $[0, 500]$ before metric calculation.
  • Optimization: Adam optimizer, Smooth L1 (Huber) loss, batch size 32, max 60 epochs with early stopping on validation loss (patience 12) across random seeds (42, 123, 456).

4. Limitations

  • Six Stations: Delhi NCT has over 40 active monitoring stations. The 6 CAAQMS stations represent primary corridors, but outer peripheral rural zones are unmodeled.
  • Three Years: Data spans 2023–2025 (1,096 days). Multi-year climate shifts or once-in-a-decade extreme meteorology are outside this window.
  • Winter-Only Test Set: Validation occurs during the monsoon season (July–Sept; lowest annual pollution), whereas the test set is during severe winter inversion (Oct–Dec; peak smog spikes). The test set has only 92 days.
